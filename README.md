# Network Anomaly Service

**Интеллектуальный сервис потокового анализа сетевого трафика для обнаружения аномалий информационной безопасности в реальном времени**

Выпускная квалификационная работа. Университет ИТМО, направление 11.03.02 «Инфокоммуникационные технологии и системы связи», образовательная программа «Программирование в инфокоммуникационных системах».

**Автор:** Дармороз Максим Дмитриевич, группа К3421  
**Научный руководитель:** Иванов С.Е.

## О проекте

Сервис принимает сетевой трафик, агрегирует его в статистические признаки по временным окнам, оценивает окна методами машинного обучения и интерпретируемыми правилами, сохраняет события и отображает аномалии на веб-дашборде в режиме реального времени.

Проект развивает подход, апробированный в рамках производственной практики: от оффлайн-анализа заранее собранных данных к непрерывной потоковой обработке и полноценному сервису с API, хранилищем и интерфейсом мониторинга.

## Цель

Разработать интеллектуальный сервис потокового анализа сетевого трафика, обеспечивающий обнаружение аномалий информационной безопасности в реальном времени, хранение и визуализацию событий, а также возможность адаптации моделей под конкретную сеть.

## Задачи

1. Проанализировать подходы, методы и аналоги обнаружения сетевых аномалий, сформулировать требования к сервису.
2. Спроектировать архитектуру потоковой обработки: сбор трафика, брокер сообщений Apache Kafka, извлечение признаков, детекция, хранение и визуализация.
3. Реализовать потоковый захват трафика и агрегацию признаков по скользящим временным окнам.
4. Реализовать ML-детекторы (Isolation Forest, LOF, One-Class SVM) и rule-based детектор, предусмотреть их совместное использование.
5. Разработать бэкенд на FastAPI и хранилище событий на PostgreSQL.
6. Разработать веб-дашборд на React для мониторинга аномалий и истории инцидентов.
7. Провести оценку на CICIDS2017, UNSW-NB15 и собственных данных; измерить Precision, Recall, F1, FPR и задержку обработки.
8. Развернуть сервис в Docker, подготовить документацию и автоматизированные тесты.

По результатам разработки планируется подготовить материалы для регистрации программы для ЭВМ как результата интеллектуальной деятельности.

## Технологический стек

| Компонент | Технология | Назначение |
|---|---|---|
| Захват трафика | Scapy, PF_RING | Live-захват пакетов и загрузка PCAP |
| Потоковая передача | Apache Kafka | Буферизация и передача окон между модулями |
| Извлечение признаков | pandas, NumPy | Статистические и энтропийные признаки по окнам |
| Детекторы | scikit-learn | Isolation Forest, LOF, One-Class SVM |
| Бэкенд | FastAPI | REST API и управление сервисом |
| Хранение | PostgreSQL | События, признаки и история инцидентов |
| Веб-интерфейс | React | Дашборд мониторинга в реальном времени |
| Развёртывание | Docker, Docker Compose | Запуск сервиса одной командой |
| Тестирование | pytest | Модульные и интеграционные тесты |
